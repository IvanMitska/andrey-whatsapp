# WhatsApp Chat Archive

Статический HTML-просмотр экспортов чатов WhatsApp с медиа. Двуязычный
интерфейс (RU / TH), тайский перевод сообщений подставляется под оригиналом.

## Страницы

- `index.html` — главная, список публичных чатов
- по странице на каждый чат (`<slug>.html`), slug строится из имени папки

## Структура

- `build_chat.py` — генератор HTML из `_chat.txt`
- `WhatsApp Chat - <имя>/` — экспорт чата (txt + медиа), авто-обнаруживается
- `translations/<slug>.json` — кэш тайских переводов (ключ — sha1 текста)
- `translate_chat.py` — авто-перевод чата через Google Translate
- `netlify.toml`, `robots.txt` — конфиг деплоя, запрет индексации
- `photos-wh/` — исходные скриншоты (в git не попадает, см. `.gitignore`)

## Регенерация

```bash
python3 build_chat.py
```

Генератор читает `_chat.txt` в каждой папке чата и пересобирает `index.html`
+ по странице на чат.

## Доступ по PIN

Все страницы закрыты PIN-гейтом на JS. Коды заданы в начале `build_chat.py`:

```python
ARCHIVE_PIN = "4726"                               # index.html + публичные чаты
CHAT_PINS = {"joseph-creative-aluminium": "8351"}  # свой PIN на отдельный чат
```

Изменил значения → `python3 build_chat.py` → пуш. Введённый PIN запоминается
в `localStorage` отдельным ключом на каждую область, поэтому PIN приватного
чата не открывает остальной архив и наоборот.

> **Чего гейт не делает.** Это клиентская защита: HTML страницы приходит в
> браузер целиком, и текст переписки можно достать через «Просмотр кода» или
> с отключённым JS. Медиафайлы лежат отдельными файлами и доступны по прямой
> ссылке (у приватного чата имена дополнены случайным суффиксом, чтобы их
> нельзя было угадать). От случайного посетителя защищает, от того, кто
> целенаправленно копает, — нет. Если нужна настоящая защита — HTTP Basic
> на Netlify Pro или шифрование контента.

## Приватные чаты

Слаги в `PRIVATE_CHATS` (`build_chat.py`) рендерятся как отдельная страница:
без бокового меню, без ссылки «Все чаты» и без карточки на `index.html`.
Ссылку на такой чат можно кидать наружу — остальной архив с неё не виден.

## Деплой

Сайт статический. Netlify хостит файлы из корня (`publish = "."`) — push в
`main` триггерит авто-деплой.
